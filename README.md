# fullstack-blog

A modern full-stack blog application built using MongoDB, Express, React, and Node.js featuring secure authentication.
A full-stack role-based blogging platform built with the MERN stack, where users can read blogs, authors can write drafts, and admins control publishing.
The system enforces proper access control, content moderation, and a clean reading experience.

# Clone the repo

git clone https://github.com/yourusername/fullstack-blog.git
cd fullstack-blog

# Backend Setup

cd backend
npm install
npm start

# env

PORT=5000
NODE_ENV=development
MONGO_URI=your_mongo_connection
JWT_ACCESS_SECRET=""
JWT_REFRESH_SECRET=""
ACCESS_TOKEN_EXPIRE=""
REFRESH_TOKEN_EXPIRE=""

# frontend

cd frontend
npm install
npm start
